# Fly Menu Fabric Mod

This Fabric client-side mod adds a right-shift menu with toggles for:

- Fly
- 5x Fly Speed
- No Fall

## Requirements

- Java 21
- Fabric Loader
- Minecraft 1.21.1

## Build

```bash
./gradlew build
```

The jar will be created in `build/libs/`.

## Usage

- Start Minecraft with Fabric
- Put the built mod jar into `.minecraft/mods`
- Press Right Shift to open the menu

## Notes

This mod is designed for personal/private server use and is client-side.
